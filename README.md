# Экономика своего VPN

Калькулятор вложений и окупаемости платной VPN-подписки для iPhone и Android: реклама в Telegram, три варианта запуска (бот с готовыми клиентами, свой Android-клиент, свои приложения в сторах), помесячный план на 24 месяца, факты и риски. Расчёт на 2 ноября 2026, курс ЦБ 80 ₽/$.

**Открыть страницу:** https://daniilglushko.github.io/vpn-economics/

Ползунки меняют допущения (чек, рекомендации, бюджет на рекламу в Telegram, цена платящего, отток, серверы, комиссии), цифры пересчитываются сразу. Ваше время и разработка в деньгах не считаются.

Чтобы открыть без интернета: скачайте `index.html` (Code → Download ZIP) и откройте в браузере.
